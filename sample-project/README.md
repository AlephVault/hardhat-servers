# Sample Hardhat Project

This project demonstrates `hardhat-servers` in a Hardhat 3 project. It comes with a sample contract, a test for that contract, and a Hardhat Ignition module that deploys that contract.

Try running some of the following tasks:

```shell
npx hardhat help
npx hardhat build
npx hardhat test
npx hardhat test --gas-stats
npx hardhat node
npx hardhat ignition deploy ./ignition/modules/Lock.js
npx hardhat serve http
npx hardhat serve ipfs
```
